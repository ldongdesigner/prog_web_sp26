# Energy System Playground

A beginner-friendly final project built with React + p5.js.

## Project idea
This interface helps users learn how solar energy, battery storage, and home demand affect a simple renewable energy system.

## Features
- React control panel with 3 sliders
- Real-time p5.js scene
- Solar output, battery storage, grid balance, and sustainability score
- Clean portfolio-style UI

## Run locally
```bash
npm install
npm run dev
```
